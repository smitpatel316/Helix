# Synthetic corpus — provenance

These 6 files were generated by `converter/tests/make-synthetic.ts` by
mutating the prism2R demo file (`prism2R-demo_dataset.prism`, MIT-licensed
test data from https://github.com/Biomiha/prism2R). Each file is one
deliberate mutation, labelled `synthetic-`; they were never written by
Prism. The mutations themselves are our own work. Redistribution is
permitted under the MIT terms of the source demo file.
